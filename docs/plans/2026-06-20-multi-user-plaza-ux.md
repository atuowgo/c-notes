# 多用户 + 精品广场 —— 产品交互稿

> 日期:2026-06-20
> 状态:**交互评审中(未实现)**。配套设计见 `2026-06-20-multi-user-plaza.md`。
> 约定:线框为 ASCII 示意,标注交互行为与状态,不代表最终视觉。

## 0. 现状基线(在此之上生长)

当前为 state 驱动单页(无 vue-router),顶栏:

```
⚗ 知识炼金炉      [收件箱] [知识网]            ＋收藏链接   💡
```

主视图 `收件箱(InboxView)` / `知识网(ClustersView)`,叠加层 `阅读器(ReaderView)` / `簇详情`。
多用户改造**保留这套结构**,新增:① 顶栏右侧用户区 + 广场 tab;② 登录叠加层;③ 广场/公开主页两个主视图;
④ 阅读器内的分享设置与社交操作。

---

## 1. 登录 / 授权(叠加层)

未登录时,任何「写」操作(收藏链接、记想法、收录、点赞、评论)或进入「我的」视图触发登录层。
浏览公开广场**无需登录**。

```
┌────────────────────────────────────┐
│            ⚗ 知识炼金炉              │
│        登录后开始炼金 / 收藏         │
│                                    │
│   [  使用 GitHub 登录          ]    │
│   [  使用 Google 登录          ]    │
│   [  微信扫码登录              ]    │
│                                    │
│   ……(邮箱登录 即将上线,置灰预留)  │
└────────────────────────────────────┘
```

**微信扫码**:点击后原位展开二维码 + 「请用微信扫码」,前端轮询登录态;扫码确认后自动关闭并刷新身份。

```
┌─────────────────────┐
│   微信扫码登录        │
│   ┌───────────┐     │
│   │ ▓▓ QR ▓▓ │     │
│   └───────────┘     │
│   等待扫码…  [返回]  │
└─────────────────────┘
```

- 登录成功 → 顶栏右侧出现头像;停留在原页面/原操作续做。
- 交互细节:GitHub/Google 走标准 OAuth 跳转回调;回调页落地后回到登录前位置(记 `returnTo`)。
- 失败/取消:回到登录层并提示,不阻塞浏览广场。

## 3. 分享设置(头像菜单 → 分享设置,叠加层)

账号级默认 + 逐篇覆盖。账号默认在这里设;逐篇覆盖在阅读器里(见 §6)。

```
┌──────────────── 分享设置 ────────────────┐
│ 我的内容默认分享级别                       │
│   ○ 私有(不进广场)         ← 默认       │
│   ○ 仅只读                                │
│   ○ 允许收藏                              │
│   ○ 允许收录                              │
│   ○ 允许公开批注                          │
│   ○ 允许评论                              │
│                                          │
│ 说明:级别向下兼容——「允许评论」自动含     │
│ 只读/收藏/收录/批注。单篇可在阅读器单独覆盖。│
│                                  [保存]   │
└──────────────────────────────────────────┘
```

权限单调:选高级别即解锁其下全部能力(对应 `ShareLevel` enum)。

## 4. 精品广场(主视图)

三条流,顶部子 tab 切换;默认「发现」。

```
[广场]
┌── 发现 ──┬── 关注 ──┬── 话题 ──┐
│
│  🔥 本周精选                          [质量分▾ 最新]
│  ┌────────────────────────────────────────────┐
│  │ 深入理解 LLM 推理优化              ⭐ 92     │
│  │ 😊 阿陈 · 3天前 · #LLM #推理                 │
│  │ 摘要:本文从 KV-cache 谈起……                 │
│  │ 🔖收藏 12   📥收录 8   👍赞 24   💬评论 5    │
│  │ [🔖] [📥收录] [👍] [打开阅读]               │
│  └────────────────────────────────────────────┘
│  ┌────────────────────────────────────────────┐
│  │ …下一张卡片…                                 │
│  └────────────────────────────────────────────┘
│  (无限滚动 / 分页)
```

- **发现流**:全平台公开文章,默认按 `质量分 × 新鲜度` 排序;可切「最新」。
- **关注流**:我关注用户的最新公开内容(未关注任何人时引导去发现流找人关注)。
- **话题流**:按 AI 聚类主题分组浏览(复用 cluster),每个主题一行横滑卡片。
- 卡片操作按生效分享级别**渐进显示**:只读级只有 `[打开阅读]`;允许收藏才出 `[🔖]`;允许收录才出 `[📥收录]`;允许评论/批注才在阅读页出对应入口。无权限的按钮不显示(非置灰),避免误导。
- 质量分 `⭐` 角标 = 行为分(收录/点赞/收藏/评论)+ AI 深度分,hover 显示构成明细。

## 6. 阅读器内的分享与社交(ReaderView 扩展)

### 6a. 自己的文章 —— 顶部加分享控件

```
[← 返回]  文章标题                      🔄刷新  [分享:私有 ▾]
```

`[分享:私有▾]` 下拉即逐篇覆盖账号默认(选项同 §3);改完即时生效,顶部出「已公开,可在广场查看」toast + 「复制公开链接」。

### 6b. 他人的公开文章 —— 按级别出现操作条

```
[← 返回]  文章标题                         😊 来自 阿陈
─────────────────────────────────────────────────────
正文……
  ┃ 被公开批注的段落会有左侧色条,点开看批注  ← (ANNOTATABLE)
─────────────────────────────────────────────────────
底部操作条(吸底):
  👍 赞(24)   🔖 收藏   📥 收录到我的知识库   💬 评论(5)
```

- **收录**:点 `📥收录` → 弹轻量确认 + 可填一句「我的笔记」(`collection.personal_note`)→ 入我的知识库(链接引用)。成功 toast「已收录,可在收件箱查看」。
- **公开批注**(ANNOTATABLE):划选正文 → 浮起 `记私有想法 / 发公开批注` 二选一。公开批注在正文左侧显色条,所有人可见;私有想法走原 `note` 流程仅自己可见。
- **评论**(COMMENTABLE):底部 `💬评论` 展开线程式评论区(楼中楼一层)。
- 级别不足时对应操作**不出现**(如只读级只有 `👍`/无,收藏级多 `🔖`)。

### 6c. 收录后的「我的视图」标识

收录的文章进入收件箱,卡片左上角带 `📥 收录自 阿陈` 角标,与自己原创收藏区分;原文撤回时显示「原文已撤回」+ 保留我的本地笔记。

## 8. 状态与边界(交互层面)

- **未登录浏览广场**:可看可滚,任何写操作触发登录层,登录后续做(不丢上下文)。
- **权限渐进**:操作按生效级别出现而非置灰——只读级看不到收藏/收录按钮,避免点了才被拒。
- **私域/公域切换**:`收件箱/知识网` 是「我的」,`广场` 是公共;头像菜单的「我的主页」是「我对外的样子」。三者心智清晰。
- **原文撤回**:收录方阅读时见占位 + 保留本地笔记;广场列表自动隐藏已转私有/删除的文章。
- **空态**:广场关注流无关注 → 引导发现流;我的主页无公开内容 → 引导去分享设置或逐篇公开。
