深入理解 LLM 推理优化
arxiv.org · 原作 · 2026-06-12

AI 提炼

推理优化的核心矛盾是显存带宽 vs 吞吐。KV-cache 是主战场,PagedAttention 解决碎片,投机解码用小模型起草、大模型校验换取墙钟加速。

大语言模型在推理阶段的瓶颈,往往不在算力而在显存带宽。每生成一个 token,都要读取完整的 KV-cache……

PagedAttention 借鉴操作系统的分页机制,把 KV-cache 切成固定大小的块,按需分配,显著降低了显存碎片。┃ 💬 阿陈的公开批注:这一段是 vLLM 的核心,值得反复读

投机解码(speculative decoding)则换了个思路:用一个小模型快速起草若干 token,再让大模型一次性校验……
